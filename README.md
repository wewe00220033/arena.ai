# OSRS — Arena AI × Antigraft

نسخة مجمعة من ملفات مشروع [OSRS](https://github.com/wewe00220033/OSRS)، مع تعديلات محافظة وسجل تسليم بين الوكيلين. **المحتوى كامل بالنسبة إلى الملفات المتتبّعة في النسخة الأصلية، وليس توزيعاً جاهزاً لكل الاعتماديات الخارجية.**

## ابدأ هنا
1. اقرأ [بروتوكول التعاون](COLLABORATION.md).
2. اقرأ [حالة Arena AI](Arena%20AI/STATUS.md) و[تسليم الاختبار](Arena%20AI/HANDOFF.md).
3. راجع [دليل النسخة المحافظة](OSRS_Bot/README_AR.md).
4. راجع [الدليل الأصلي المحفوظ](README_UPSTREAM.md) باعتباره توثيقاً موروثاً، لا إثباتاً لنجاح أو سلامة التشغيل.

## الهيكل
- `OSRS_Bot/`: سكربت التشغيل، solver محلي فقط، ضوابط السلامة والاختبارات ومشغلات ويندوز.
- `net/` و`microbot_stage0_*/`: ملفات Java الأصلية، دون تعديل في هذه الجولة.
- ملفات الرادار والدراسات والأدلة: محفوظة من الأصل.
- `Arena AI/`: حالة وتقارير وتسليم Arena AI.
- `Antigraft/`: قوالب فقط حتى يكتب Antigraft حالته ونتائجه بنفسه.
- `UPSTREAM_MANIFEST.json`: مصدر كل ملف متتبّع وما إذا عدلناه أو غيرنا موضعه.

## اختبار محلي بدون الاتصال باللعبة
```sh
cd OSRS_Bot
python -m unittest -v test_safety.py
python -m py_compile run_stronghold_bot.py safety.py osrs_ai_solver.py
```

يتطلب Python 3.10+ وخادم Agent محلياً متوافقاً على `127.0.0.1:8081`، وتوكن اللعبة المحلي خارج Git. افتح `OSRS_Bot/تشغيل_النسخة_المحافظة.bat` أو المشغل الرئيسي في نفس المجلد. لا تستخدم أدوات إصلاح ويندوز أو المشغلات الأخرى عشوائياً؛ بعضها موروث وله مسارات خاصة بجهاز المصدر.
