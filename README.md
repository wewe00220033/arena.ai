# Stronghold — conservative local runner

نسخة تجريبية تتوقف عند أخطاء المسار وقراءة الدم والطعام، بدلاً من متابعة خطوات قد تكون في موقع غير صحيح.

**ابدأ من [دليل التشغيل والحدود بالعربية](README_AR.md).**

## الملفات
- `run_stronghold_bot.py`: مسار التشغيل مع ضوابط التوقف.
- `safety.py`: فحص الموقع والدم والطعام والتحقق من نتائج الطلبات.
- `osrs_ai_solver.py`: إجابات محلية فقط، بدون Groq أو مفاتيح خارجية.
- `test_safety.py`: اختبارات محاكاة.
- `تشغيل_النسخة_المحافظة.bat`: تشغيل ويندوز، يتطلب Python 3.10+.

## التحقق محلياً
```sh
python -m unittest -v test_safety.py
python -m py_compile run_stronghold_bot.py safety.py osrs_ai_solver.py
```

لا توجد مكتبات Python خارجية مطلوبة. يلزم خادم Agent المحلي المتوافق مع صيغة API الموثقة في الدليل. لا تضع توكنات أو بيانات حسابات في المستودع.

## حدود التحقق
نجحت 12 حالة محاكاة وفحص الصياغة محلياً. لم يتم اختبار اتصال حي باللعبة، أو تأكيد مسار الأبواب والإحداثيات، أو استلام المكافآت والإيداع فعلياً. توقف السكربت لا يوقف قتال اللعبة؛ المراقبة والتحكم اليدوي ضروريان. استخدام الأتمتة قد يخالف قواعد اللعبة.
