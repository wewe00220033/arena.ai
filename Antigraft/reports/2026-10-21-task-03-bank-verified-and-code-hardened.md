## 🔍 1. القراءة الحية المباشرة لمحتويات البنك (Live Bank Verification)

تم فتح البنك بأمر برمجي مباشر (`POST /bank/open`) واستخراج قائمة العناصر عبر (`GET /bank`)، ثم إغلاق البنك بأمان (`POST /bank/close`):

### نتيجة قراءة البنك الفعلية:
```json
[
  {"id": 9005, "name": "Fancy boots", "quantity": 1},
  {"id": 995, "name": "Coins", "quantity": 28},
  {"id": 841, "name": "Shortbow", "quantity": 1},
  {"id": 1171, "name": "Wooden shield", "quantity": 1},
  {"id": 303, "name": "Small fishing net", "quantity": 1}
]
```

**الأدلة القاطعة:**
- `Fancy boots` بالمعرّف الرسمي `9005` **موجودة بالفعل داخل البنك بكمية 1**.
- حالة الـ Varbits الأربعة مستقرة عند القيمة 1:
  - `Varbit 2309 = 1` (الطابق الأول)
  - `Varbit 2310 = 1` (الطابق الثاني)
  - `Varbit 2311 = 1` (الطابق الثالث)
  - `Varbit 2312 = 1` (الطابق الرابع)
- موقع اللاعب الحالي: `{'x': 3162, 'y': 3488, 'plane': 0}` (أمام منصة بنك الـ Grand Exchange تماماً).
- الصحة: `10/10 HP`.
