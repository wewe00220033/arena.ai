## ⚽ 2. قانون ضربات الجزاء والاستئناف الذكي (Penalty Shootout & Smart Resume)

> **القاعدة الحاكمة:**  
> في ضربات الجزاء، لو فريق متقدم 4-2 والماتش خلص، الضربة الخامسة ما بتتلعبش!  
> لو اللاعب أو زيزو أو سليم أو كرما لعبوا يدوي وعدوا طابق أو استلموا صندوق، **البوت لا يعيد ما تم إنجازه نهائياً**، بل يقرأ حالة السيرفر فورياً وينفذ الخطوة التالية فقط.

### محددات الحالة الحية (Ground-Truth State Check):
1. **أين أنا الآن؟ (`read_progress()`):**
   - هل على السطح؟ (`py < 5000`)
   - هل في الطابق 1؟ (`1855 <= px <= 1935 and 5180 <= py <= 5250`)
   - هل في الطابق 2؟ (`1980 <= px <= 2060 and 5180 <= py <= 5250`)
   - هل في الطابق 3؟ (`2110 <= px <= 2185 and 5240 <= py <= 5315`)
   - هل في الطابق 4؟ (`2300 <= px <= 2380 and 5180 <= py <= 5260`)
   - موقع خارج هذه الحدود $\rightarrow$ `UNKNOWN_REGION` $\rightarrow$ توقف فوري لحماية الحساب.
2. **ماذا أنجزت حتى الآن؟ (`varbits` 2309..2312):**
   - `Varbit 2309 == 1` $\rightarrow$ مكافأة الطابق 1 مستلمة $\rightarrow$ تخطي غرفة الصندوق والتوجه لسلم الطابق 2.
   - `Varbit 2310 == 1` $\rightarrow$ مكافأة الطابق 2 مستلمة $\rightarrow$ تخطي غرفة الصندوق والتوجه لسلم الطابق 3.
   - `Varbit 2311 == 1` $\rightarrow$ مكافأة الطابق 3 مستلمة $\rightarrow$ التوجه مباشرة لسلم الطابق 4.
   - `Varbit 2312 == 1` $\rightarrow$ مكافأة الطابق 4 مستلمة $\rightarrow$ الخروج عبر البوابة للسطح.
3. **هل الحقيبة تحوي الجزمة؟ (`/inventory`):**
   - إذا كانت `Fancy boots` موجودة بالحقيبة واللاعب على السطح $\rightarrow$ التوجه للبنك للإيداع.
   - إذا كانت المكافآت مكتملة والشنطة خالية من الجزمة (مودعة سابقاً) $\rightarrow$ توقف نظيف (`STOP_COMPLETED`).
4. **حارس الطعام المنفذ فعلياً (`SafetyController`):**
   - الكود يشترط وجود أي طعام مطبوخ في الحقيبة، ويأكل تلقائياً عند هبوط الـ HP عن 8.
   - لا يوجد شرط مفروض في الكود لحد أدنى للعدد (كالقول `food >= 2`)؛ بل الفحص الصارم لوجود طعام صالح قبل وأثناء أي حركة.
